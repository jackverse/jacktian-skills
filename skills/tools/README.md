# tools — 独立小工具类

「造工具」类可复用经验：Windows 桌面常驻/托盘工具、命令行辅助管线、单文件可执行产物打包等，与具体业务项目无关。

| 子目录 | 范围 | 现有 skill |
|--------|------|-----------|
| （平铺） | Go 桌面/托盘工具与单文件 EXE 打包 | go-win-tray-exe |

## 约定

- 技能内容不得包含具体项目的密钥、内网地址、业务数据或其他敏感信息。
- 同类经验优先更新现有 skill；出现新的独立主题（如 PowerShell 管线、Rust/Python 打包、安装器制作）时再建平级目录并更新本表。
- **生效方式不变**：sync.ps1 递归发现所有 SKILL.md，在 `~/.zcode/skills/` 平铺 junction，skill 目录名（=name）必须与技能名一致，勿改。
