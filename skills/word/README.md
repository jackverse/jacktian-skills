# word — Word 文档类

产出或处理 Word/docx 文件的技能。

| Skill | 定位 |
|-------|------|
| word-toolkit | 通用 Word/docx 处理技能集(模板生成/反向对齐/图片回填/踩坑排查) |
| quest-poi-tl-word-export | 后端导出:quest 导出任务 + poi-tl 从 docx 样例生成 Word 报告 |

新沉淀的 Word 相关 skill 放本目录;若能力可并入 word-toolkit(通用 docx 处理),优先按其 SKILL.md 文末「沉淀规范」补充进 word-toolkit 而非新建。
