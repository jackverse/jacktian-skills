# 专题:::IMG:: 截图占位框回填真实图片

build_docx.py 生成的文档里,`::IMG::题注` 是一个"灰字【截图占位:题注】的单格边框表 +
框下方居中题注段",等真实截图就绪后批量回填。回填是机械活,**唯一的坑在题注匹配**。
题注本身该起什么名、各节该留哪些占位(注明按钮、审核通过/不通过成对、登录方式
各一),是写源 md 时的内容纪律,见 manual-writing.md——回填救不了写坏的名。

## 用脚本(推荐)

```bash
python scripts/fill_img_placeholders.py 文档.docx \
  --img "系统总体结构图=shots/arch.png" --img "功能模块图=shots/modules.png" \
  [--width 14] [--dry-run]
```

- 先 `--dry-run` 看匹配报告,确认无"未匹配"再真跑。
- 退出码 1 = 还有占位框没回填或键名对不上(文件仍已保存,可分批迭代)。
- 依赖仅 python-docx；不传 `--width` 时按所有节的最小正文可用宽度（页宽减左右页边距）自动插图，可用 `--width` 指定更窄的厘米值。
- 原路径保存遇 `PermissionError` 时会备份原文件并另存带时间戳的“附图版”，不强制关闭用户 Word；后续渲染验收应针对日志给出的实际产物。

## 题注匹配纪律(核心教训)

- 占位文字必须用正则 `【截图占位：(.+?)】` 提取**完整题注**后做**全等**匹配。
- **严禁子串包含匹配**:拿题注去 `cell.text` 里做 `in` 判断,"系统总体结构图"会误命中
  "大赛系统总体结构图"的占位框——两个框被填进同一张图,而且错的那个还覆盖了正确文字。
- 同理,键名表(题注→图片路径)维护后先 dry-run 对一遍账,比回填完再逐页目检便宜得多。

## 手工要点(不用脚本时照此实现)

1. 遍历 `doc.tables` 顶层表格(占位框是 build 生成的顶层单格表;合并单元格按 `_tc` 去重)。
2. `re.search(r"【截图占位：(.+?)】", cell.text)` 提取题注,与图片映射**全等**比对。
3. 回填:清空占位单元格**全部段落 runs**(保留段落对象)→ 段落居中 →
   `p.add_run().add_picture(path, width=Cm(14))`;多余段落删除,只留首段。
4. 占位框**下方的题注段保持不动**(它不属于占位框单元格)。
5. 回填后按 template-generate.md 的渲染校验流程出 PDF/PNG 逐页目检一遍。

## 跨文档复用截图（直改 OOXML）

场景：把文档 A（已插好截图）中可复用的图复制到文档 B 对应截图占位。例如从机构手册复制 8 张图到企业手册时，不能只复制 `document.xml` 中的 `<w:drawing>`；以下四件事必须同时处理，缺一都可能导致 Word 报“文件可能已经损坏”：

1. **复制媒体文件**：把源图片复制到目标包的 `word/media/`，按目标文档现有媒体文件重新编号，不能沿用可能冲突的源文件名。
2. **添加图片关系**：在目标 `word/_rels/document.xml.rels` 中为每张图新增 image 关系；新 `rId` 从目标文档现有最大 `rId` 的下一个值开始依次分配，`Target` 指向刚复制并重编号后的媒体文件。
3. **替换占位段**：将目标 `word/document.xml` 中的占位段替换为含 `<w:drawing>` 的段落。drawing 可从源文档整块复制，但必须把 `r:embed` 改为目标文档的新 `rId`，并把 `wp:docPr id` 改为目标文档中不冲突的值。
4. **补齐内容类型**：目标 `[Content_Types].xml` 必须有 `<Default Extension="png" ContentType="image/png"/>`（其他图片格式同理）。**无图文档首次插图最容易漏这一条，Word 会直接报文件损坏**；机构手册向企业手册复制 8 张图的实战中实际踩中过。

定位与保护：

- 占位段名称在 XML 中可能被拆成多个 run，不能用连续字符串硬匹配；应按段落聚合所有 `w:t` 文本后再匹配占位名称。
- 目标占位所在段落已经含图片的，要跳过保护，不能重复替换或覆盖。
- 图题段保留不动，只替换截图占位段。

## 时机建议

- 占位框先出文档、评审定稿后一次性回填,避免"改一图重建一次"。
- 回填后再要改内容时:**改 md 源重新 build + 重新回填**(回填映射留档),不要在回填版上
  手改正文——手改在下次重建时必丢。
