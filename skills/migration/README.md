# migration — 系统迁移与数据对齐类

沉淀跨项目可复用的新旧系统迁移排查方法，重点关注旧行为取证、业务口径逆向、数据基线对照和迁移后的回归验证；不绑定具体前端框架、后端语言或数据库。

| 子目录 | 范围 | 现有 skill |
|--------|------|-----------|
| （平铺） | 旧 SPA 接口逆向、线上基线获取、旧库复算、新旧明细与统计口径对齐 | migration-data-parity |

## 约定

- 同类迁移口径排查优先更新现有 skill；出现数据迁移脚本、字段映射等独立主题时再建平级目录并更新本表。
- 技能内容不得包含真实域名、内网地址、账号密码、token、连接串或可识别业务数据；接口与 SQL 仅保留脱敏示例。
- 旧系统与旧库默认只读，不得为排查调用有副作用的旧接口。
- **生效方式不变**：sync.ps1 递归发现所有 SKILL.md，在 `~/.zcode/skills/` 平铺 junction，skill 目录名（=name）必须与技能名一致，勿改。
